嵌入你的 Google Form

打开你的 Google Form → 右上角 发送 / Send → 选 🔗 链接 → 复制 → 粘贴到下面 → 按「保存」。

💡 建议把表单的「需要登录」关掉，这样嵌入后同学可以直接填写。填完的回复会自动进入你的 Google Sheet。

填写出席表单

从 Google Sheets 导入出席数据

  1. 打开绑定 Google Form 的那份 Google 表格（Form 页面 → 「回复」→ 「在 Google 表格中查看」）。
  2. 菜单：文件 → 下载 → 逗号分隔值 (.csv)。
  3. 把 CSV 文件拖到下面，或者用记事本打开 CSV，全选复制、粘贴到下面的框里。
  4. 按「解析并导入」——系统会自动按 Student ID + 会议日期 去重并生成统计。
如果 CSV 里没有「日期」这一列，就用这个日期给所有记录填上。

Name：Name / 姓名 / 名字
Phone Number：Phone / Phone Number / HP / Mobile / 电话 / 手机号 / 联系号码
Meeting Date：Date / Meeting Date / 日期 / 会议日期
